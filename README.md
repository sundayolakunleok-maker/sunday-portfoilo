## 🚀 5. Local Setup & Development

### Prerequisites
- Node.js (v18 or LTS) & npm
- Python 3.8+ (for running standalone Flask backend suites)

### Installation
```bash
# Clone the repository
git clone https://github.com/sundayolakunleok-maker/sunday-okegbemi-portfolio.git
cd sunday-okegbemi-portfolio

# Install frontend dependencies
npm install

# Start Vite local development server
npm run dev
```
Open `http://localhost:3000` to view the website.

### Production Build
```bash
npm run build
```
The compiled static assets are generated in `dist/`.

## 🌐 6. Netlify Deployment
